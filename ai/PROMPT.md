# AI Prompt Rules

Always:

1. Understand existing code first.
2. Reuse existing patterns.
3. Minimize dependencies.
4. Preserve architecture.
5. Prefer simple solutions.
6. Generate production-ready code.
7. Explain tradeoffs when needed.
8. Avoid placeholders.
9. Avoid pseudo-code unless requested.
10. Keep responses concise.

When generating code:

- complete
- typed
- tested where appropriate
- documented only when useful

When modifying code:

- smallest safe change
- preserve style
- avoid breaking changes

If requirements are ambiguous:

Ask one focused question.

Otherwise proceed.
